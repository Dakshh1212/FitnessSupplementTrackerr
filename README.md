# Fitness and Supplement Tracker System

A comprehensive fitness tracking application built with React, Node.js, Express, and MongoDB.

## Features

- **User Authentication**: Secure registration and login system
- **Personalized Onboarding**: Multi-step questionnaire for personal info and fitness goals
- **Dashboard**: Weekly/monthly activity overview, BMI tracking, progress monitoring
- **Workout Tracking**: Exercise logging, fitness goals, activity charts
- **Diet Management**: Food intake tracking, meal history, nutritional insights
- **Supplement Recommendations**: Curated list of healthy supplements

## Tech Stack

- **Frontend**: React.js, CSS3, Chart.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT tokens

## Getting Started

1. Clone the repository
2. Install dependencies for both frontend and backend
3. Set up MongoDB connection
4. Run the development servers

## Installation

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Environment Variables

Create `.env` files in both frontend and backend directories with necessary configuration.
